# Image Denoising using Edge-Aware Deep Learning

This project implements a hybrid deep learning model for image denoising.

## Features
- Gaussian noise simulation
- CNN based denoising
- Edge-aware refinement
- PSNR and SSIM evaluation

## Technologies Used
- Python
- TensorFlow
- OpenCV
- Google Colab

## Results
The proposed method preserves edges while removing noise more effectively than traditional filters.
